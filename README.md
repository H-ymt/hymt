Personal Website built with Astro and Cloudflare Workers

## Stack

- Astro 7
- TypeScript
- Cloudflare Workers
- Cloudflare KV
- Biome

## Deploy

```bash
pnpm deploy
```

## Preview

```bash
pnpm preview
```

## Fetch Knowledge

```bash
pnpm fetch-knowledge
```

## Sync KV

```bash
pnpm sync-kv
```

## Upload Assets

```bash
pnpm upload-assets
```
